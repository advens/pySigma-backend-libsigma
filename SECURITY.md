# Security

Report a bug in rule compilation, artifact bytes, or correlation JSON
privately to jeremie.jourdin@advens.fr. Do not open a public issue for
a bug that would make the matcher accept a rule it should reject, or
reject a rule it should accept, before a fix ships.

Matcher and loader bugs belong to libsigma. Report those to the same
address and see libsigma `SECURITY.md`.
